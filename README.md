# Active Directory Certificate Services (AD CS) & EFS

## 📌 Project Overview

This project demonstrates the implementation of an **on-premises Public Key Infrastructure (PKI)** using **Active Directory Certificate Services (AD CS)** and **Encrypting File System (EFS)** in a Windows Server 2022 domain environment.

The lab establishes an internal **Enterprise Root Certificate Authority**, enrolls domain users for EFS-capable certificates, and demonstrates cryptographically enforced file confidentiality.

## 🎯 Objective

The project was designed to demonstrate how **Active Directory, AD CS, and EFS** work together to provide identity-based cryptographic protection for sensitive files.

The implementation covers:

* Enterprise Root Certificate Authority deployment
* Certificate enrollment for domain users
* EFS certificate-based file encryption
* Cryptographic access control
* Verification of authorized and unauthorized file access

The project demonstrates that possessing a valid domain account or NTFS permissions alone does not provide access to an EFS-encrypted file without the corresponding **private key**.
